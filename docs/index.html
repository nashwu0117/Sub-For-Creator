WHY SUB FOR CREATOR

從語音到成片，
把字幕工作變簡單。

不用在多個工具之間來回切換，從辨識、校對到匯出都在同一個工作流程裡完成。

01 / TRANSCRIBE

AI 自動辨識，
逐字對齊。

使用 WhisperX 產生精準的逐字時間戳，讓字幕不只「有字」，還能跟著聲音準確出現。

00:01.20每一句話00:02.86都有自己的時間00:04.12
02 / EDIT

在時間軸上，
調整每一個細節。

播放器、字幕列表和 wavesurfer 時間軸同步，拖曳、分割、編輯都能即時預覽。

03 / EXPORT

一份字幕，
適配每個平台。

從剪輯軟體用的 FCPXML，到社群影片用的燒錄 MP4，一次匯出你需要的版本。

.SRT.VTT.ASS.MP4.WEBM
04 / PRIVATE BY DEFAULT

不註冊，也能安心使用。

匿名 session、不收集姓名與 Email；處理完的檔案會在 48 小時後自動刪除，不拿你的內容訓練模型。

01

Docker 一鍵部署

適合想快速啟動完整服務的使用者。需要 Docker、Redis，以及能執行語音辨識的主機。

TERMINAL
cp .env.example .env docker compose up -d --build # 開啟 http://localhost:8080
02

本地開發

前端使用 React + Vite，後端使用 FastAPI + Celery；可分開啟動 API、worker 與網頁。

TERMINAL
git clone https://github.com/nashwu0117/Sub-For-Creator.git cd Sub-For-Creator npm --prefix frontend install npm --prefix frontend run dev
需要 GPU？使用 WhisperX；只有 CPU 也可以切換至 faster-whisper。查看 README
